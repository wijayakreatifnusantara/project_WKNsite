# Panduan Pengguna & Dashboard WKNsite

Selamat datang di dashboard WKNsite yang telah dimodernisasi. Dokumen ini menjelaskan fitur-fitur utama dan cara berinteraksi dengan antarmuka baru yang premium.

## 📊 Dashboard Overview

Dashboard adalah pusat kendali aplikasi Anda. Dirancang untuk memberikan informasi paling kritis secara instan.

### 1. Hero Section (Banner Utama)
- **Jam & Tanggal Real-time:** Memastikan sinkronisasi waktu operasional.
- **Tombol Refresh:** Gunakan tombol sinkronisasi (ikon putar) di pojok kanan bawah banner untuk menarik data terbaru dari Spreadsheet tanpa memuat ulang halaman.
- **Status Koneksi:** Indikator di Topbar menunjukkan apakah sistem terhubung ke database cloud atau berjalan dalam mode lokal.

### 2. Kartu Statistik (Quick Stats)
- **Total Karyawan:** Menampilkan jumlah total personil aktif.
- **Pengeluaran Gaji:** Estimasi total payout periode berjalan.
- **Rata-rata Gaji:** Indikator kesehatan finansial organisasi.
- *Tip: Klik pada kartu statistik untuk langsung menavigasi ke halaman detail terkait.*

### 3. Grafik Tren Finansial
- Menampilkan visualisasi pengeluaran gaji selama 6 bulan terakhir. Data ini sangat berguna untuk perencanaan anggaran (budgeting).

## 🔔 Sistem Notifikasi

Sistem notifikasi telah dioptimalkan untuk meminimalkan gangguan ("Noisy Notifications").

- **Notifikasi Penting:** Muncul dalam bentuk Toast di pojok kanan atas untuk kejadian kritis seperti kegagalan login atau error database.
- **Latar Belakang:** Proses pemeliharaan otomatis (seperti auto-correction data) kini berjalan tanpa mengganggu pandangan Anda.
- **Pusat Notifikasi:** Klik ikon Lonceng di Topbar untuk melihat riwayat pesan sistem.

---

## 📱 Akses Mobile

Aplikasi ini sepenuhnya responsif:
- **Desktop:** Sidebar tetap terlihat di sisi kiri.
- **Tablet/Mobile:** Sidebar akan tersembunyi. Gunakan tombol **Hamburger (☰)** di pojok kiri atas untuk membuka menu navigasi.
