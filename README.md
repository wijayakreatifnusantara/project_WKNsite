# WKNsite: Premium HR & Payroll Management System

WKNsite adalah platform manajemen SDM (HRIS) dan Payroll tingkat korporat yang dirancang untuk kecepatan, keamanan, dan estetika premium. Platform ini mengintegrasikan basis data karyawan yang kompleks dengan mesin payroll otomatis dan sistem pemantauan kehadiran berbasis AI.

## 🚀 Fitur Utama

- **Dashboard Premium:** Visualisasi data real-time dengan metrik pengeluaran, tren finansial, dan pengingat kontrak.
- **Sistem Payroll Otomatis:** Perhitungan gaji bersih (THP) dengan dukungan untuk lembur, BPJS, PPh 21, dan potongan pinjaman.
- **Navigasi Cerdas:** Sidebar yang dapat dilipat (collapsible) dengan pengelompokan kategori logis untuk alur kerja yang lebih ringkas.
- **AI Error Handler:** Penanganan kesalahan cerdas yang memperbaiki masalah data secara otomatis di latar belakang.
- **Responsivitas Tinggi:** Desain mobile-first yang memungkinkan akses penuh dari desktop maupun perangkat seluler.

## 📁 Struktur Proyek

- `/docs`: Panduan pengguna dan dokumentasi teknis mendalam.
- `/js`: Logika aplikasi, mesin payroll, dan layanan AI.
- `/assets`: Aset visual, logo, dan ikon sistem.
- `index.html`: Struktur utama aplikasi.
- `style.css`: Sistem desain (Design System) korporat.

## 🛠️ Persiapan Pengembangan

1. Pastikan Anda memiliki browser modern (Chrome/Edge direkomendasikan).
2. Konfigurasi `SCRIPT_URL` di `js/api-config.js` untuk menghubungkan ke backend Google Sheets.
3. Gunakan `Ctrl + F5` setelah melakukan perubahan pada CSS untuk menghindari isu caching.
