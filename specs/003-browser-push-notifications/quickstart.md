# Quickstart: Browser Push Notifications

## Setup

1. Open the WKNsite dashboard on `localhost` or an `https` domain.
2. Look for the "Notifikasi" section in the dashboard (usually in Settings or Sidebar).
3. Click **"Aktifkan Notifikasi"**.
4. Allow the browser permission prompt.

## Testing

To verify the feature is working:
1. Click the **"Tes Notifikasi"** button in the settings.
2. Minimize the browser or switch to another tab.
3. A notification should appear on your desktop within 2 seconds.
4. Click the notification to return to the WKNsite tab.

## Troubleshooting

- **No prompt appears**: Check if you have already blocked notifications in the browser's site settings (click the lock icon in the URL bar).
- **Notifications don't show**: Ensure your Operating System is not in "Do Not Disturb" or "Focus" mode.
